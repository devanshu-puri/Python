1, Add an expense
Enter amount, category, description and date.

2. View all expenses
Display all previously recorded expenses.

3. Calculate total expenses
Calculate how much money you've spent.

4.Category-wise spending
Calculate spending on food, travel, shopping, etc.

5.Delete an expense
Remove an incorrectly recorded transaction.

6.Save expenses permanently
Store data in a JSON file so information survives after closing the program.

7.Monthly expense report
Generate a summary of your spending.

Variables	            Store expense details

Lists	                Store multiple expenses
Dictionaries	        Represent individual expenses
Functions	             Organize application logic
Loops	                Display menus repeatedly
Conditional statements	Handle user choices
Exception handling       Handle invalid inputs

Modules	                Organize code

================================================================================================

Application follows this flow:
1. User starts the application.
2. Application displays a menu.
3. User selects an operation.
4. Application performs that operation.
5. Application displays the result.
6. Menu appears again until the user exits
